# Image Processing (IPP) Practical Assignments

This repository contains the Jupyter notebook solutions for Practical File 1 and Practical File 2 for the Image Processing (IPP) course.

---

## Repository Structure

* `Practical_File_1_Image_Processing.ipynb` — Solutions covering basic image reading, format conversion, transformations, color spaces, and MSE evaluation (Programs 1–10).
* `Practical_File_2_Image_Processing.ipynb` — Solutions covering edge detection, compression estimates (RLE, Huffman, DCT), texture segmentation, morphology, contours, and denoising (Programs 1–10).
* `requirements.txt` — Python package dependencies required to run the notebooks.
